# dvrk display refactor workspace

This repository is being split into two ROS 2 packages:

- `dvrk_data`: data acquisition, GStreamer transport, processing, timestamps,
  recording, playback, and test sources.
- `dvrk_console`: surgeon/operator-facing display, overlay, calibration, and
  control applications.

Documentation can be found in https://dvrk.readthedocs.io

Touchscreen setup notes can be found in [touchscreen.md](touchscreen.md).
